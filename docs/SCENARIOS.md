# Как проверить шесть сценариев

Откройте приложение: `http://localhost:8000` (как запустить — в [README](../README.md)).
Вход: страница **«Войти»** → блок **«Демо-доступ»** → нажмите на карточку аккаунта. Пароль у всех демо-аккаунтов — `demo1234`.
Сменить аккаунт: меню аватара в правом верхнем углу (☰ + аватар) → **«Сменить аккаунт»**.

> Если база осталась от предыдущей версии, сначала пересоздайте её — схема изменилась.
> Все даты в демо-данных считаются от текущего дня. Чтобы вернуть данные в исходное состояние, пересоздайте их: `python -m app.seed --reset` (локально) или удалите файл `data/app.db` и перезапустите контейнер.

|---|---|
| `user@demo.ru` | Илья С., обычный пользователь |
| `user2@demo.ru` | Анна И., обычный пользователь |
| `org@demo.ru` | Олег К., владелец одобренного шахматного клуба «Ход» |

## 1. Своё направление: создать событие и найти его

1. Войдите как **`user@demo.ru`**.
2. Нажмите **«+ Создать активность»** (на телефоне — круглая кнопка «Создать» внизу).
3. Название: `Фрисби в Нескучном саду`.
4. В поле «Направление» напишите `Алтимат фрисби` → нажмите появившуюся кнопку **«+ Добавить своё: «Алтимат фрисби»»**.
5. Укажите дату (например, завтра), адрес — `Нескучный сад, главная поляна`. Остальное можно не трогать.
6. Нажмите **«Опубликовать»**.
   **Результат:** откроется страница события с цветной шапкой и пометкой направления «Алтимат фрисби».
7. Смените аккаунт на **`user2@demo.ru`**. На главной введите в поиск `фрисби`.
   **Результат:** в «События в Москве» есть карточка «Фрисби в Нескучном саду». В ряду направлений появился чип «Алтимат фрисби» — код при этом не менялся.
8. Откройте карточку — страница события открывается, есть кнопка **«Записаться»**.

## 2. Организация: заявка, отказ, одобрение, публикация

1. Войдите как **`neworg@demo.ru`** → **«Сообщества»** → вверху кнопка **«Создать организацию»**.
2. Заполните форму (например: «Клуб скандинавской ходьбы «Шаг»», описание, направление «Скандинавская ходьба», город — из списка, контакты) → **«Отправить заявку»**.
   **Результат:** вверху «Сообществ» появилась карточка **«Моя организация»** с жёлтой плашкой **«Заявка на рассмотрении»**: от имени организации публиковать нельзя, публичной страницы нет. В форме создания активности нет выбора «от чьего имени», в списке «Все сообщества» клуба нет. У администратора в колокольчике — «Новая заявка организации».
3. Смените аккаунт на **`admin@demo.ru`** → **«Админка»** → вкладка **«Заявки организаций»**.
4. У новой заявки нажмите **«Отклонить»**, впишите причину (например, «Добавьте адрес тренировок») → **«Отклонить»**.
5. Вернитесь в **`neworg@demo.ru`** → **«Сообщества»**.
   **Результат:** в карточке «Моя организация» красная плашка **«Заявка отклонена»** с текстом причины, форма заполнена прежними данными. В колокольчике — «Заявку организации отклонили» с причиной.
6. Исправьте описание → **«Отправить заявку снова»**.
7. **`admin@demo.ru`** → «Админка» → «Заявки организаций» → **«Одобрить»**.
8. **`neworg@demo.ru`** → «Сообщества»: в карточке «Моя организация» зелёная плашка «одобрена» → **«Создать мероприятие от организации»**.
   В блоке «От чьего имени» уже выбрана организация. Заполните название, направление, адрес → **«Опубликовать»**.
   **Результат:** событие сразу опубликовано без повторной модерации. Оно видно на главной с подписью «Организация». В «Сообщества» → «Публичная страница» оно есть в разделе «Мероприятия».

> Быстрый вариант: у **`pending@demo.ru`** заявка «Волейбольное сообщество «Пляж»» уже ждёт решения — её можно сразу одобрить или отклонить из админки.

## 3. Свободная запись

1. Войдите как **`user2@demo.ru`** → на главной найдите **«Велопрогулка по набережной»** (подпись «Частное лицо», плашка «Свободная запись»).
2. Откройте карточку → **«Записаться»** → в окне с условиями нажмите **«Записаться»**.
   **Результат:** тост «Вы записаны!», зелёная плашка **«Вы записаны»**, Анна И. появилась в списке участников. В **«Мои активности» → «Я участвую»** событие со статусом «Вы записаны».
3. Смените аккаунт на **`user@demo.ru`** (организатор) → откройте то же событие.
   **Результат:** блок **«Управление» → «Участники»** — в списке Анна И.

## 4. Запись по заявке: принять и отклонить

У Анны (`user2@demo.ru`) уже есть две заявки к шахматному клубу.

1. Войдите как **`user2@demo.ru`** → **«Мои активности»**.
   **Результат:** «Вечер быстрых шахмат» и «Шахматы для начинающих» со статусом **«Заявка на рассмотрении»**.
2. Смените аккаунт на **`org@demo.ru`** → откройте **«Вечер быстрых шахмат»** → блок **«Управление» → «Заявки»** → у Анны И. **«Принять»**.
3. Откройте **«Шахматы для начинающих»** → у Анны И. **«Отклонить»**.
4. Вернитесь в **`user2@demo.ru`** → «Мои активности».
   **Результат:** у «Вечера быстрых шахмат» — **«Вы записаны»**, у «Шахмат для начинающих» — **«Заявка отклонена»**. На страницах событий те же статусы. В колокольчике — «Вашу заявку приняли» и «Заявку отклонили».
5. Олег снова открывает «Шахматы для начинающих»: Анны нет ни в «Участниках», ни в счётчике — она только на отдельной вкладке **«Отклонённые»**. Анна может убрать отклонённую заявку из «Моих активностей» кнопкой **«Убрать из списка»**.

Подать новую заявку: **`neworg@demo.ru`** → «Шахматы для начинающих» → **«Подать заявку»** → статус «Заявка на рассмотрении», у Олега она появится во вкладке «Заявки».

## 5. Обсуждение и ответ организатора

1. Войдите как **`user2@demo.ru`** → откройте **«Вечер быстрых шахмат»** → блок **«Обсуждение»**.
2. Напишите вопрос (например, «Нужно ли приносить свои часы?») → **«Отправить»**.
3. Смените аккаунт на **`org@demo.ru`** → то же событие → под вопросом Анны нажмите **«Ответить»**. Над полем появится цитата вопроса с крестиком отмены. Напишите ответ и нажмите **«Отправить»** (или Ctrl+Enter).
   **Результат:** ответ Олега стоит под вопросом с отступом, на зелёном фоне, с меткой **«Организатор»**. Вопрос Анны — обычное сообщение с её именем. Анне приходит уведомление «Вам ответили».

## 6. Модерация: снять мероприятие

1. Войдите как **`admin@demo.ru`** → **«Админка»** → вкладка **«Мероприятия»**.
2. Найдите **«Стритбол в Лужниках»** (на него записан Илья) → **«Снять»** → впишите причину → **«Снять с публикации»**.
   **Результат:** статус «Снято с публикации», причина видна в строке.
3. Откройте главную — стритбола нет ни в ленте, ни в поиске.
4. Войдите как **`user@demo.ru`** → **«Мои активности»**.
   **Результат:** у «Стритбола» статус **«Мероприятие снято»** и причина, в колокольчике — «Мероприятие снято: …». Если открыть событие, вверху будет плашка «Мероприятие снято с публикации: …», а запись закрыта. Запись можно убрать из списка кнопкой «Убрать из списка».
5. Войдите как **`neworg@demo.ru`** и откройте то же событие по прямой ссылке (адрес вида `/events/5`).
   **Результат:** «Мероприятие недоступно». Попытка записаться через API (`POST /api/events/5/join`) вернёт 409 «Мероприятие снято с публикации, записаться на него нельзя».

Дополнительно:
- **Скрыть сообщение.** Под `admin@demo.ru` откройте «Вечер быстрых шахмат» → в обсуждении у любого сообщения нажмите **«Скрыть»** с причиной. Остальные пользователи увидят «Сообщение скрыто модератором», остальная переписка останется. Администратор видит оригинал и причину.
- **Удалить.** В админке → «Удалить» с причиной: мероприятие пропадает отовсюду, кроме списка админа с фильтром «Удалены».
- В демо-данных уже есть снятое мероприятие «Ночной забег по центру» с записью Ильи.

## Проверка правок второго прогона

| Правка | Где проверить |
|---|---|
| 1. Отклонённые не в участниках | Сценарий 4, шаг 5: вкладки «Заявки / Участники / Отклонённые» в «Управлении», счётчики считают только подтверждённых |
| 2. Шапка и «Сообщества» | «Профиль» больше нет в шапке и таб-баре; организация создаётся и отслеживается в «Сообществах» (сценарий 2) |
| 3. Меню пользователя | Меню аватара → «Профиль» открывает публичный профиль с кнопкой «Редактировать» (имя, город, о себе); есть «Мои активности», «Сменить аккаунт», «Выйти» |
| 4. Подпись организатора | Карточки на главной: «Частное лицо» или «Организация»; та же подпись на странице события в блоке «Организатор» |
| 5. Email и город | «Регистрация»: `test@fsdkf;j.ru`, `a@b`, `a@@b.ru` отклоняются с «Введите корректный email»; город выбирается только из списка с поиском (попробуйте «красн») |
| 6. Ответы в обсуждении | Сценарий 5: «Ответить», цитата с крестиком, ответ под исходным сообщением, Ctrl+Enter, счётчик символов |
| 7. Убрать из списка | `user@demo.ru` → «Мои активности»: у снятого «Ночного забега» есть «Убрать из списка», у активных записей кнопки нет |
| 8. Уведомления | Колокольчик в шапке (на телефоне — «Уведомления» в таб-баре): напоминания о событиях в ближайшие сутки, «Вам ответили», решения по заявкам и организациям, снятие события; клик открывает нужный экран, «Прочитать все» обнуляет счётчик |
